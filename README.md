# The Winds Homestay (React + Vite)

    npm install
    npm run dev      # local preview
    npm run build    # production build in /dist

Edit content in `src/data.js`. Photos live in `src/assets`. The hero photo uses a WebGL shader (`src/HeroGL.jsx`).
Please verify the 4.9 rating, the room count, the review, distances and prices before publishing.
